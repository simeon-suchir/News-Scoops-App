# News-Scoops-App
A Python-based News Application built with Tkinter GUI and MySQL backend. Designed for users to get effective news feed and equip them with the latest news updates.

📰 NEWS SCOOPS
A Python Desktop News Application
📌 Overview

News Scoops is a Python-based desktop news application built using Tkinter and SQLite.
It delivers real-time news, article previews, live weather & time, and PDF export through a smooth and user-friendly interface.

✨ Features

🔐 User login & account creation
🗞️ Live news via NewsAPI
🏆 Categories → Top Headlines | Business | Technology | Science | Sports | Health | Entertainment
📰 Article preview with image & source link
🌦️ Weather + 🕒 time dashboard
📄 PDF export of top headlines
🔄 Reload & back navigation

🛠️ Tech Stack

💻 Python 3.10
🎨 Tkinter | TkinterWeb | TkHTMLView
🗄️ SQLite
🌐 NewsAPI | OpenWeatherMap API

🏗️ Architecture

➡️ API data fetched in JSON
➡️ Parsed & stored in SQLite
➡️ Rendered dynamically in Tkinter GUI

🚀 Run Locally

➡️ Clone repository

git clone https://github.com/simeon-suchir/News-Scoops-App.git


➡️ Install dependencies

pip install requests pillow pandas fpdf tkhtmlview tkinterweb


➡️ Run application

python main.py
